# SpamDetector - Advanced Threat Analytics

A modern AI-powered email spam detection platform that analyzes 
emails in real-time and identifies potential threats, phishing 
attempts, and spam content.

## Features
- 🔍 Real-time spam detection
- 🛡️ Advanced threat analytics
- 📊 Visual threat scoring dashboard
- ⚡ Instant results
- 🎨 Clean modern dark UI

## Tech Used
- HTML, CSS, JavaScript
- Tailwind CSS
- Google Fonts (Inter)

## How to Use
1. Paste your email content
2. Click Analyze
3. Get instant spam score and threat breakdown
